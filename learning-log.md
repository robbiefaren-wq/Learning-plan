ГЛАВНАЯ ТЕМА:
  Мнение до урока:
    VAR - Это переменная имеющая функциональную облость видимости. VAR можно перезаписывать и менять в ней данные на прямую. При изменении не будет ошибок. Устаревшая переменная, не используют.
    LET - Это переменная имеющая блочную облость видимости, за пределами {} не будет виден. Данную переменную нельзя перезаписывать, но ее можно менять. Ее используют, когда нужен какой-то счетчик или, то что будет постоянно меняться.
    CONST - Это переменная имеющая блочную облость видимости, так же как и LET не будет виден за пределами {}. Данную перменную нельзя, ни перезаписывать, ни менять в ней данные. Но const можно менять только содержимое в ссылки. То есть, const содержит только ссылку на данные, но сами данные менять можно. Нельзя менять только ссылку. Так же const это константа, что означает постоянное, не изменяемое значение.

    ОБЛОСТЬ ВИДИМОСТИ (SCOPE) - Это место где находится код, где он живет. Например есть глобальная обость видимости, блочная и функциональная. Глоабльная облость видимости, означает, что перменные могут использоваться в любом месте кода. Функциональная это относится к var за пределами функций не будет виден, но в глобальной системе если была объявлена переменная, будет все отлично. Блочная, тоже самое, только все будет упираться именно в {}.

  Устаревшее ключевое слово "var" Вывод:
    Var - Это устаревший способ хранения данных. Когда еще не было толком лексического окружения. Var может перезаписываться и так же еще менять данные. Отличия от let который не может перезаписываться, будет ошибка. Это помогает от не удачной потери данных. Так же еще var не имеет блочной облости видимости. То есть, если объявить переменную var в условиях if или циклах, то мы сможем применять данные этой переменной за пределами этих if или цикла. Var живет только в функциональной облости видимости. За пределами функции, перменную нельзя будет применять, только дальше в глубине функции. 


  Вопрос: где хранится переменная и какой момент наступает, когда срабатывает колбэк при var и при let. 
    setTimeOut(() => {
      for (let/var i = 0; i < 3; i++) {
        setTimeout(() => console.log(i), 1000);
      }
    }, 1000);

    При let на каждую итерацию цикла создаётся своё отдельное лексическое окружение (своя копия i: 0, 1, 2), и каждый из трёх колбэков привязывается к своей копии.
    
    При var переменная i одна общая на весь цикл — к моменту запуска колбэков цикл уже закончился, в этой единственной переменной лежит 3, и все три колбэка берут её.
