ГЛАВНАЯ ТЕМА: 
  Мнение до урока: 
    VAR - Это переменная имеющая функциональную облость видимости. VAR можно перезаписывать и менять в ней данные на прямую. При изменении не будет ошибок. Устаревшая переменная, не используют. 
    LET - Это переменная имеющая блочную облость видимости, за пределами {} не будет виден. Данную переменную нельзя перезаписывать, но ее можно менять. Ее используют, когда нужен какой-то счетчик или, то что будет постоянно меняться. 
    CONST - Это переменная имеющая блочную облость видимости, так же как и LET не будет виден за пределами {}. Данную перменную нельзя, ни перезаписывать, ни менять в ней данные. Но const можно менять только       
      содержимое в ссылки. То есть, const содержит только ссылку на данные, но сами данные менять можно. Нельзя менять только ссылку. Так же const это константа, что означает постоянное, не изменяемое значение. 

    ОБЛОСТЬ ВИДИМОСТИ (SCOPE) - Это место где находится код, где он живет. Например есть глобальная обость видимости, блочная и функциональная. Глоабльная облость видимости, означает, что перменные могут
      использоваться в любом месте кода. Функциональная это относится к var за пределами функций не будет виден, но в глобальной системе если была объявлена переменная, будет все отлично. Блочная, тоже самое, только все будет упираться именно в {}.
